# 무빙 머지 슈터 (Moving Merge Shooter)

슬링샷을 사용하여 움직이는 새들을 맞추고 합체시켜 진화시키는 게임입니다.

## 게임 방법

1. 슬링샷을 당겨서 발사합니다
2. 같은 레벨의 새를 맞추면 합체되어 다음 레벨로 진화합니다
3. 새가 15마리 이상이 되면 게임 오버입니다
4. 최고 레벨인 용(🐉)까지 진화시키세요!

## 설치 및 실행

```bash
# 의존성 설치
npm install

# 개발 서버 실행
npm run dev

# 프로덕션 빌드
npm run build
```

## 기술 스택

- React 18
- Vite
- Tailwind CSS
